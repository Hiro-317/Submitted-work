作品詳細(チーム製作) ->

	制作情報 ->
		
		開発環境 -------> VisualStudio2022
		動作環境 -------> PC(Windows11,10)
		使用言語 -------> C++20
		使用ライブラリ -> DXライブラリ、ENet
		制作人数 -------> 3人
		ジャンル -------> 3Dアクション
		制作期間 -------> 2か月
		
		
	ゲーム説明 ->
	
		協力型３Ⅾボスバトルアクションゲーム
		ローカル通信で、最大4人まで協力して遊べます。
		
		ボスのHPを 削り切ったら 勝ち
		プレイヤーのHPが尽きたら負け
		
		というシンプルなルールです。

	担当箇所 ->
		
		ボス全般、カメラの調整、エフェクトのベース

		
	作品のアピールポイント ->
		
		ボスの状態管理 ->
			
			それぞれの状態で可塑性と拡張性を持たせるため
			ステートデザインパターンを使用し、可能にしました。
			
			通信同期では、座標や回転のみを同期させステート情報はホストのみ持つ
			そうすることによって、ホストとのズレを少なくしました。

		トマトの表現 ->
			
			楕円形の特徴を表現するため、カプセル形状のコライダ複数設置し再現しました。
			また、移動も転がるようにして表現しました。
					
作品詳細(個人製作) ->

	制作情報 ->
		
		開発環境 -------> VisualStudio2022
		動作環境 -------> PC(Windows11,10)
		使用言語 -------> C++20
		使用ライブラリ -> DXライブラリ
		制作人数 -------> 1人
		ジャンル -------> 3Dアクション
		制作期間 -------> 5か月
		
		
	ゲーム説明 ->
	
		３Ⅾハンティングアクションゲーム
		
		プレイヤーとボスが1対1で限られたステージの上でタイマンで戦っていくというゲームです。
		特徴としては、「部位が破壊可能」になっている点です。
		
		ボスのHPを 削り切ったら 勝ち
		プレイヤーのHPが尽きたら負け
		
		というシンプルなルールです。

		
	作品のアピールポイント ->
		
		部位破壊 ->
			
			フレーム間でのカプセルコライダを実装し、それぞれにHPを付与することで可能にしました。
			部位破壊をすることで、攻撃や移動の弱体化を起こすことができます。

			また、部位破壊の際、SEやエフェクト、フレームの除去を行なうことで
			プレイヤーにわかりやすいように伝えることができました。
			
		爽快感 ->
			
			回避や攻撃の際のSEや画面揺れを起こし、
			プレイヤーに攻撃してる感を与えるようにしました。

			また、強化されるとより画面揺れを大きくしたりと、
			爽快感を与えるようにもしました。
